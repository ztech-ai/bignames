# 图片署名与许可

核对记录：2026-11-15；本批事实截止2026-11-13。全站224张本地肖像，另有奥特加1个经用户确认的姓名占位。图片跨八语共享，不依赖运行时外链图片。

本批30张真实彩照由AI查看本地文件，对照具名来源说明核对主体、作者和许可；逐人采编记录保存文件SHA-256及检查边界。此前194张图片及姓名占位保留。署名字段和程序检查不等于法律或身份认证。

在世人物保留原图色彩，已故人物由统一样式显示黑白，不修改原始图。孔子、达·芬奇是后世画像。照片拍摄时间不等于资料核对日，旧队服和场景不表示现有任职。

基普耶贡照片按来源保留GFDL 1.2或以后版本、原作者与无不变章节等声明；完整许可随静态站点提供：[GFDL 1.2全文](../public/assets/licenses/GFDL-1.2.txt)。文本取自系统提供的未修改标准GNU许可副本（`/usr/share/common-licenses/GFDL-1.2`）；许可原文地址亦保留在图片元数据中。
