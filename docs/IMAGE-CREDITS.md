# 人物图片来源与使用许可

核对日期：2026-11-13。每张图片均已根据 Wikimedia Commons 文件说明、人物条目中的图像关联核对身份，并对本地联络图进行视觉复核。24 张图片均已本地保存，网站运行时不依赖外链图片。

以下许可针对图片各自生效；请在后续部署和复制时保留作者、来源及许可链接。Public domain（公有领域）的具体依据以对应 Commons 文件说明页为准；该标识不是另行授予许可。版权状态与肖像、人格等其他权利并不相同。

孔子图片为西汉时期的后世壁画，不能据此确认其生前相貌；达·芬奇图片为传归弗朗切斯科·梅尔齐的肖像作品。二者标为画像，不标为照片。阿达·洛夫莱斯使用的是 Antoine Claudet 拍摄的银版照片。

下载 Commons 提供的预览或原始文件；未生成或篡改人物面部。文件本身可能是来源页面标注的既有裁切版本，详见来源历史。网页缩放和裁切仅用于版式展示。人物数据中的 `death` 字段统一决定展示色彩：在世人物保留原图色彩，已故人物使用黑白效果；首页、列表、详情和打印遵循同一规则，悬停也不恢复已故人物的原图色彩。原始素材文件与署名许可保持不变。
