# 当代千人扩充 · 2026年11月

## 本轮范围

从科技、商业、政治和文化开始，按公共影响力门槛筛选；适当扩展科学医学、体育与探索。领域不设硬性配额。目标是 **1000位新增候选**，与已有24份完整档案分别管理。已有档案的履历更新和影响力评级按用户要求留到下一轮，不在这次自动改写。

实际检索截止日为 **2026-11-13**。不预写本月后续事件。来源访问日期、来源版本日期、年表实际覆盖日期分别保留；取得了2026年的网页，不等于其全部内容已更新到2026年。

## 五星方法

机器可读规则：`data/collections/influence-method.json`。综合公共影响范围、代表成果的深度、结构性改变和持续性。

| 星级 | 含义 |
| --- | --- |
| 5 | 全球范围的深远、持久或时代性影响 |
| 4 | 领域内世界级影响，成果对多国具有明确作用 |
| 3 | 跨国、重大地区或关键专业领域的结构性影响 |
| 2 | 国家或专业圈的显著影响，未达到本轮门槛 |
| 1 | 局部或新兴影响，长期作用仍待观察 |

本轮最低三星，不为凑够人数提高评级。候选评分均注明 `provisional`、理由、日期和方法版本；经来源审阅的评分才可转为 `reviewed`，并须补充支持链接。星级是可修订的编辑判断，不是道德判断、科学测量或人的价值排名。不同领域使用同一尺度时仍存在判断空间，因此页面同时呈现主要影响范围。

## 数据分层与完成标准

1. `data/research/rosters/`：各领域初选与备选池，附实际查阅的领域来源。
2. `data/collections/contemporary-1000.json`：去重、排除本轮已知已故者和原有已发布人物后的正式1000人选择。
3. `data/research/queue/<id>.json`：一人一份采编任务，列明身份、生存状态、近期履历、来源、照片、八语一致性等待办。
4. `data/research/evidence/<id>.json`：实际抓取的公开职业事实、来源版本、八语实体名称、日期精度和图片许可。始终标记为待编辑核验，不直接成为发布资料。
5. `data/research/drafts/<id>.json`：一人一份共享事实和8语言视图的编辑草稿，保留缺失字段和语言回退，不作为正式简历发布。
6. `data/people/<id>.json`、对应图片和7份非中文译文：完成逐人核验后才进入网站正式档案。
7. `data/research/editorial/<id>.json`：每位新增正式人物的采编与肖像核验记录。

网站分别显示选入、来源采集和完整档案的数量。正式档案至少含6条有来源的倒序事件、2项代表成果、2项资料来源、图片来源与许可，以及完整的8语言正文。照片统一从基础数据 `death` 字段控制色彩；只有核验后才可以写入表示在世的 `null`。候选没有 `death` 字段，也不会因此被当作已核验在世。

对公开资料中的无结束日期职位不自动断言“现任”；教育结束日期不自动转成毕业或获得学位；仅有年份的日期不补月日。宣布的投资、上映、离任等未来计划保留“计划”语义，年表以公告日期记录。

## 可重复运行的采编流程

```sh
# 合并已评星的领域池；输出正式名单、任务文件和选择报告
node scripts/assemble-collection.mjs

# 公共资料采集，支持缓存、断点续采、限速与同名身份检查
python3 scripts/research-fetch.py --roster data/collections/contemporary-1000.json --resume

# 新发现的已故状态、同名问题修正后，再选择备选并补齐来源
node scripts/assemble-collection.mjs
python3 scripts/research-fetch.py --roster data/collections/contemporary-1000.json --resume

# 从同一证据记录生成可编辑的八语事实草稿
node scripts/research-drafts.mjs

# 正式档案和译文完成后，进行全站验证
npm run build
npm run check
npm test
python3 tests/research-fetch.test.py
```

采集只发生在开发阶段，浏览器访问的网站依然只有静态文件，不依赖数据库或后台。原始缓存不打包进静态网站。

## 后续批次

按五星与四星人物优先、来源完整度、跨地区覆盖安排采编。每批完成中文底本、八语正文、照片核验和一致性检查，再更新实际完成数量。剩余待审资料保持明确的待审状态。千人初选完成不等于千份简历完成，也不等于全部人物已通过最新生存状态和履历审核。

原有24份资料通过 `data/research/baseline.json` 记录原始内容散列，本轮校验确保未被自动改动。网站部署问题保持暂停；不要推送到会自动触发 Pages 的 `main` 分支。
